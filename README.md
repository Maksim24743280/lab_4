## Формат текстового файла

Кодировка: **UTF-8**. Одна фигура — одна строка.

| Тип           | Формат строки                      | Пример                |
|---------------|------------------------------------|-----------------------|
| Круг          | `Circle <радиус>`                  | `Circle 5.0`          |
| Прямоугольник | `Rectangle <ширина> <высота>`      | `Rectangle 3.0 4.0`   |

- Пустые строки пропускаются.
- При ошибке в любой строке (неизвестный тип, неверное число параметров, ошибка преобразования числа, недопустимый параметр) **загрузка отклоняется целиком** — выбрасывается `InvalidFigureFormatException` с номером строки и причиной.
- Уже прочитанные фигуры при ошибке не возвращаются.

## Собственные исключения

| Исключение                     | Базовый класс      | Тип           | Когда используется                                              |
|--------------------------------|--------------------|---------------|-----------------------------------------------------------------|
| `InvalidParameterException`    | `RuntimeException` | непроверяемое | Конструкторы фигур: ≤ 0, NaN, Infinity, `null`-основание       |
| `InvalidFigureFormatException` | `Exception`        | проверяемое   | Разбор текстового файла: формат, число, неизвестный тип        |

**Почему так выбрано:**
- Параметры конструктора — ошибка вызывающего кода → **unchecked**.
- Формат внешнего файла — данные, которые нужно обрабатывать → **checked**, объявляется в `throws`.
